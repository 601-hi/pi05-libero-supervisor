# 按几何体对的碰撞门 CPU 里程碑（2026-09-26）

## 被否决的旧假设

旧门只保存每个状态的全局最小自碰撞距离和环境距离，再比较两个标量是否改善。GPU日志证明最近几何体对会在手掌、两根手指、柜体多个网格和目标物体之间切换。不同pair的两个最小值没有连续物理含义，因此“最小值增加”不能证明某个具体接触正在解除。

## 新证据结构

MuJoCo evaluation-only oracle现在除原最小值外，还在候选起点和终点保存全部距离不超过1 cm的几何体对及其有符号距离。正常轨迹每步检查点仍走原只读最小值路径，不额外枚举所有pair；只有恢复候选端点和恢复动作后的审计才请求pair集合，避免无意义开销。

## 新门控语义

对自碰撞pair和机器人—环境pair分别执行同一规则：

- 起点已有深接触：终点必须至少改善10微米，或离开跟踪集合；
- 起点处于数值零带：不得变成新的明确穿入；
- 起点为正间隙但位于5 mm缓冲内：只能增加间隙；
- 起点未进入1 cm跟踪集合、终点却出现明确负距离：视为新碰撞并拒绝；
- NaN、无穷值等无效证据fail-closed。

这不是对柜体或目标物体做语义白名单。允许的是“同一个已有接触对逐步解除”，而不是“接触某个任务物体都算安全”。全局最小值门暂时保留为附加约束，pair门必须同时通过。

## 测试与后续实验纪律

新增测试复现GPU发现的pair切换反例：手掌—柜体旧接触改善，但手指—另一柜体网格新出现70 mm负距离时必须拒绝；同时覆盖已有穿入改善、接触消失和接触加深。完整回归445项通过。
