# 混合回退真实微步闭环里程碑

日期：2026-09-25

## 范围

本轮只开放“真实hold稳定 + oracle候选评分 + 一次受限OSC微步 + 实际响应监督”，不开放连续脱困或整段倒序回放。目的在于验证状态机、碰撞评分、控制器和执行后监督能形成同一条因果链。

## 首次闭环

task0 prefix30重放后，机器人真实hold 15步才满足连续稳定。候选评分选择−X 5 mm，控制器实际产生约−0.554 mm主方向位移，窗口响应为safe，状态机保持`safe_escape`并请求重新评分。

首次评分的总风险为0.851。分解后发现历史管道偏离占0.742，但hold后当前状态本身已经偏离0.0903 rad，候选将其改善到0.0818 rad。协议因此和已有接触一样改为基线相对变化，修正后总风险降为0.669；动作与实际响应保持一致。

## 跨接触阶段隔离微步

- prefix40：选择向上5 mm；桌面相关有符号距离由−251.6 mm改善为−236.7 mm，实际向上0.662 mm，响应safe；
- prefix60：候选总风险0.877，旧门允许执行且实际响应safe；
- prefix70：候选总风险0.890，预测碗接触由−0.2 mm恶化为−1.2 mm，实际响应被执行后监督判replan，状态机回到hold。

后两例说明只对单项风险设置0.9硬门不够：多个中等风险可形成高总风险。新增总风险上限0.85后，prefix60和70均不再执行任何候选，而是保持`safe_escape`并输出`reduce_step_and_rescore`。该决策发生在执行前，不再依赖执行后拦截。

## 结论与限制

状态机已经能够在真实MuJoCo控制周期中完成稳定等待、候选选择、单步执行、实际响应检查和拒绝后的状态转移。当前缩步重评仍只是协议请求，候选生成器尚未实际缩小到2 mm以下；连续脱困、连续汇合门和关节状态倒序回放仍未开放。
