## 冻结的新配对契约

下一轮只启动一次模型服务，并在同一服务生命周期内顺序运行：

1. 无监督器 baseline；
2. 相同环境 seed、相同采样噪声的 control；
3. control 完成后立即运行因果前缀审计。

首次 `complex_rollback_proposal` 的 action 为干预边界 `k`。合法比较前缀严格定义为 `[0,k)`，因为 action `k` 已允许被回退器修改。审计逐元素比较：

- intended action；
- executed action；
- 末端执行前/后位置；
- 关节执行前/后位置；
- 干预前 inference 的采样噪声哈希序列。

任何非零差异都会使脚本以失败状态退出，并写明第一处分叉；只有严格前缀完全一致才允许比较 baseline/control 最终成功率。输出目录存在时运行脚本拒绝覆盖，避免悄悄用后续重跑替换冻结结果。
