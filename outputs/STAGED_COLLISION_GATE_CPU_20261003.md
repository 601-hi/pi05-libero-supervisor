# 分阶段回退碰撞门 CPU 节点（2026-10-03）

## 问题

视频和 v24f 数值共同表明，机械臂回退约 9.44 cm 后，外部环境净空已约 28.6 mm，却仍因 `link5_collision--gripper0_hand_collision` 的简化内部几何距离低于统一阈值而停止。旧实现还把同一个 `historical_corridor_floor_m` 同时传给自碰撞与环境碰撞判断；为了容忍机器人内部碰撞网格误差，理论上可能连外部环境浅穿透也一并容忍，语义不正确。

## 新的三阶段逻辑

阶段不按时间或固定动作序号划分，而由当前与预测几何证据决定，便于迁移到其他机器人和场景。

### 1. `contact_exit`

当前外部环境距离小于接触容差。保持最严格规则：已有穿透必须总体退出；接触对重新分配受限；禁止危险新接触。该阶段保留现有专用历史关节接触退出认证。

### 2. `constrained_corridor`

尚未满足开阔条件，或候选不是直接历史回放。环境继续使用 5 mm 模型误差缓冲和逐对检查。机器人自身几何与环境几何分开判断：只有自身几何能够使用历史网格容差，环境碰撞不能继承该容差。

### 3. `open_history_replay`

必须同时满足：

- 状态为 REPLAY；
- 候选是直接历史关节回放，不是自由逃逸；
- 已产生至少 5 cm 实际空间撤离；
- 当前与预测的最小环境净空均不少于 20 mm。

此时取消“每个附近几何对都必须单调增加净空”的过强要求。外部环境仍不得出现任何预测穿透；机器人自身几何只允许不低于标定历史网格下限 `-0.5 mm`。因此这是基于开阔证据的有条件降级，不是关闭碰撞门。

## 验证

- 新增阶段分类和“只放宽自身网格、绝不放宽环境穿透”的单元测试。
- 远端完整相关回归：`149 passed`。
- 对 v24f/g/h 既有轨迹作离线反事实审计：
  - v24f 只新增放行动作 230、242 的 6 个直接历史候选；
  - v24g 只新增放行动作 238 的 3 个直接历史候选；
  - v24h 尚处柜内 JOIN/接触阶段，新增放行 0 个；
  - JOIN 新增放行 0 个，轴向逃逸新增放行 0 个；
  - 所有开阔阶段候选的外部环境穿透数为 0。

结论：新门会解除视频中中后期的内部网格假阳性，但不会放宽早期接触逃逸或外部环境碰撞。下一次 GPU 应从固定故障快照验证，避免上游轨迹漂移掩盖门控变化。
