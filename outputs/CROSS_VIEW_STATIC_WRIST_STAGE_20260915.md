# 固定视角—腕部视角交叉监督阶段（2026-09-15）

## 用户提出的修正

用户指出，固定相机对静止背景的判断应与机械臂腕部相机交叉验证，从而弥补单视角单应矩阵无法完整表达深度差、视差、遮挡和相机自运动的问题。这一修正把原“静止背景共识”推进为两个互补物理事实：固定视角判断物体是否相对世界运动；腕部视角判断物体是否相对夹爪保持稳定附着。

## 实现

新增跨视角状态机，显式输出：

- `confirmed_attached`：固定视角确认世界运动，腕部视角确认附着；
- `static_in_world`：固定视角未见世界运动且腕部也不支持附着；
- `conflict`：两路可靠但物理结论冲突；
- `fixed_only_motion` / `wrist_only_motion`：只有一路可靠；
- `unknown`：两路证据均不足。

状态机按每路可信度决定是否采纳证据，不要求所有时刻双路硬一致。腕部视角最终应使用候选—夹爪相对位姿稳定性，而不是照搬固定视角的全局背景单应。

## Wave 2 基础审计

20条Wave 2 sidecar均同时保存逐步对齐的224×224 `agent_images`与`wrist_images`。以5帧间隔抽取659对图像，分别执行同一前后向光流、RANSAC单应与置信度估计：

- 固定视角置信度：p10=0.410、p50=0.614、p90=0.802；
- 腕部视角置信度：p10=0.143、p50=0.351、p90=0.623。

以0.5作为本次基础审计的可靠性界限：

- 两路均可靠125对（19.0%）；
- 仅固定可靠367对（55.7%）；
- 仅腕部可靠59对（9.0%）；
- 两路均不可靠108对（16.4%）。

因此，固定相机应作为世界运动主基准；腕部相机可在部分固定视角盲区提供补充，但不能把两路结果简单平均或要求硬AND。腕部全局单应较低并不代表腕部相机无用，而是支持将其改用于局部目标—夹爪附着测量。

## 尚未完成
