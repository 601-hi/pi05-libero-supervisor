# 逃逸进展 Mask GPU v4 配对节点（2026-09-27）

## 有效性说明

v3 曾错误地跨策略服务生命周期复用旧 baseline。审计发现首次介入前动作不同，因此 v3 只能作为工程烟雾测试，不能用于因果效果结论。v4 在同一个 π0.5 服务生命周期内依次运行 baseline 和 control，并固定初始状态、环境 seed 与扩散采样噪声。

v4 的 5/5 episode 在首次复杂回退动作之前，执行动作和末端位置逐项完全一致，因果配对有效。

## 局部进展

4 mm 到达容差产生了可解释的局部改善：episode 0 的回放目标推进到 57、54、51，比旧版多进入一个更早历史点；episode 2 的初始 join 用 48 步完成，随后进入参考点 66 和 62。唯一 baseline 成功 episode 3 未介入并保持成功。

## Mask 的负结果

episode 2 在参考点 62 共出现 33 个 mask 周期，并执行 6 次 `escape_axis_0_neg_1`。这些更大但被模型预测为安全的动作没有带来真实自碰间隙改善：该候选对应响应的自碰间隙约从 1.977 mm 降至 1.946 mm，最低约 1.937 mm。虽然仍保持正间隙，没有发生碰撞穿透，但“预测改善”没有兑现。

这说明仅凭停滞后降低软安全权重会放大碰撞预测模型误差。Mask 不应默认拥有控制权。后续应保留影子评分，并增加执行后安全收益否决与候选冷却：一次 mask 动作若真实间隙不增反降，立即恢复原权重并暂时禁用该候选方向/尺度。

## 当前决策

GPU 服务已自动关闭。下一 CPU 阶段将 mask 改为默认影子模式，并实现执行后否决；在离线轨迹上通过前，不再开 GPU 扩大测试。
