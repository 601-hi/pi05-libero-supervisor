# 静止背景场开发集审计

日期：2026-09-14  
范围：仅使用五条已公开的开发试点；未访问冻结 wave 1。

## 目的

检验两个假设：LIBERO agent 外部视角能否近似固定；逐帧背景补偿残差能否比原始长期净位移更可靠地识别操纵对象。

## 背景拟合质量

每隔五帧取一对相邻图像，使用 Shi–Tomasi 特征、前后向 LK 光流和 RANSAC 单应拟合。145/145 对图像产生有效模型：

- 内点率：p05 0.687，p50 0.922，p95 1.000；
- 内点重投影误差：p05 0.031 px，p50 0.315 px，p95 0.704 px；
- 4×4 网格覆盖：p05 0.625，p50 0.8125，p95 0.9375；
- 图像中心预测背景位移：p05 0.022 px，p50 0.296 px，p95 1.498 px。

结论：外部相机近似固定，多数背景共识十分稳定；但分割、光流与单应估计仍产生非零噪声，不能把“像素位移严格为零”作为静止定义。

## 被否定的简单方案

对已有55个 SAM2 候选，逐帧计算候选质心相对拟合单应的残差，并把残差绝对值累加。五个经人工确认的真实对象按该分数排名为：2、7、5、1、6，仅1/5为第一。

失败原因不是相机真的大幅运动，而是：

1. SAM2边界变化和遮挡会产生高频质心抖动；
2. 逐帧取绝对值后，正负抖动不会抵消；
3. 8自由度单应在固定相机上仍有约亚像素估计噪声；
4. 每帧把该估计噪声施加到候选，长期求和会放大；
5. 真实操纵对象可能平稳移动，累计抖动反而小于错误候选。

例如 goal 5 的真实碗原始质心路径为0.490，但背景补偿残差路径为0.205、排名第五；若仅按残差总和会选中净位移很小但边界抖动更强的候选。

## 修正后的用途

固定外部相机中，背景共识首先用于：

- 验证相机确实稳定；
- 估计本帧的背景噪声底与模型可信度；
- 在背景模型失效时输出 unknown；
- 标记长期低净位移、远离夹爪的休眠候选；
- 检查闭爪事件后目标是否脱离静止共识。

它不应直接替代现有“累计最大净位移”身份分数。候选运动应分解为低频净运动和高频抖动：

\[
S_i^{net}(t)=\max_{k\le t}\|c_i(k)-c_i(0)\|,
\qquad
S_i^{jitter}=\sum_t\|\Delta c_i(t)\|-\|c_i(T)-c_i(0)\|.
\]

前者更接近搬运位移，后者主要用于降低跟踪可信度而不是增加“被控制”分数。只有检测到真实相机运动显著超过背景拟合不确定度时，才启用背景单应补偿。

## 与冻结验证的关系

Wave 1仍按已冻结的 SAM2 多候选最大净位移方案执行，本审计不得用于修改 wave 1。背景可信度、静止候选休眠和夹爪事件条件化属于 v2 候选，只能在 wave 1错误分析后冻结，并在未打开的 wave 2验证。
