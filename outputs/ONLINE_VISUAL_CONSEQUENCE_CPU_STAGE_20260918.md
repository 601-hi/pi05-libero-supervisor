# 在线视觉后果CPU接线阶段（2026-09-18）

## 目标

将既有静止背景、光流和接触—抓取状态机接入真实在线监督循环，同时禁止把未校准的光流像素值冒充异常概率。

## 完成内容

1. LIBERO循环在每个动作后重新读取、旋转、缩放固定相机和腕部相机图像，向对象监测器提供真实`images_before/images_after`配对；此前`images_after`一直为`None`。
2. 新增`BackgroundConsequenceEvidenceScorer`：估计多数静止背景单应矩阵，并在调用者提供候选掩膜后计算候选相对背景的残余运动。
3. 测量与校准严格分离。无候选掩膜、背景无效或无冻结校准器时，独立运动与受阻概率保持`None`；原始残余像素只进入诊断日志。
4. 新增真实在线工厂`create_frozen_execution_with_visual_consequence`，将条件双专家、模糊路由、视觉后果评分和接触状态机连接起来。
5. 候选脚本新增`frozen_four_state_visual_background`模式。当前候选提供器明确为none，因此只审计背景质量并弃权，不生成假视觉报警。
6. 对象事件日志现在包含`visual_diagnostics`，可审计背景有效性、跟踪点、内点率、重投影误差、覆盖度和弃权原因。

## 真实回放背景健康度

使用可复现LIBERO-90 task 0自然失败的400帧双视角回放逐对审计：

- 固定相机：399/399对有效，有效率1.0，置信度中位数0.828，p05为0.475；
- 腕部相机：397/399对有效，有效率0.995，置信度中位数0.739，p05为0.450；
- 腕部失效动作索引为269和362。

因此该案例中静止背景参考场本身可用。双视角399对全量CPU审计在弱CPU上耗时约数分钟，在线必须由执行模糊/接触窗口选择性触发，不能每步无条件运行。

## 测试与边界

新增测试覆盖无图像、无候选、无校准器和显式校准器四种路径；全量回归193/193通过。当前尚未完成在线候选物体掩膜和冻结运动概率校准，因此不能声称视觉能够诊断抽屉未运动，也不能报告视觉准确率。

## 下一GPU阶段

先运行`frozen_four_state_visual_background`单episode，验证在线前后帧、背景诊断和弃权日志；随后只在模糊/接触窗口调用冻结候选生成器。候选生成和校准必须在与最终测试episode隔离的数据上完成。得到候选后，视觉层才可以区分未接触、接触未推动、独立物体运动和证据不足，并把机制状态交给恢复层。

## GPU在线冒烟与因果透明性（同日补充）

在固定环境seed 7、pi0.5采样噪声seed 20260918下运行LIBERO-Spatial task 0：视觉背景模式成功，74步、15次推理。68次视觉路由全部返回`background_only`并以`candidate_mask_unavailable`弃权；固定视角背景置信度中位数0.635、p05为0.458。该结果证明在线前后帧和背景诊断已实际执行，但尚未证明候选级异常识别。

首次拿该轨迹与此前另一轮策略服务生成的基线比较时，动作出现约0.002的微小差异。继续做控制变量后确认：固定噪声哈希和初始状态相同，但不同策略服务进程的第一个动作块已不同，因此跨进程轨迹不能用于判断视觉后处理是否改变控制。保持同一个策略服务进程，重新运行无视觉影子模式后，两条轨迹均为74步、15次推理，`intended_action`、`executed_action`、`eef_pos_before`和`eef_pos_after`的最大差均为0。由此严格证明当前视觉背景测量及其弃权路径在控制上透明；后续所有因果A/B比较必须优先采用同进程配对。
