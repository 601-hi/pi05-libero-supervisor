# 临时逃逸 GPU v20/v21 结果（2026-10-02）

v20将单步反馈改为同方向三步累计反馈，保持12步独立总预算。它使用全部12个逃逸动作，并在第一处受阻后成功恢复约10步direct回放，证明临时逃逸不是单纯延迟停止。最终JOIN 45、普通REPLAY 127、逃逸12；最大空间撤离7.91 cm、历史深度11，未进入重规划。

v20停止时最后两个`z-`动作相对本方向基线累计改善真实自碰净空约0.074 mm，说明12步预算确实在仍有改善时耗尽。据此v21仅把整次恢复逃逸预算从12提高到24，其他冻结条件不变。

v21使用全部24个逃逸动作，普通REPLAY增加到150步，说明增加的逃逸预算继续多次恢复了历史direct路径。历史点误差由v20末尾约21.79 mm下降至v21末尾约19.73 mm；但最大空间撤离仍为7.91 cm，历史深度仍为11，未达到10 cm交接门，任务失败。

结论：预算偏小确实是局部瓶颈，但只扩大预算呈明显低效。24步让回放延长并降低目标误差，却没有增加最大撤离或历史深度。下一步不再把总预算机械提高到几十或上百步，而应在无卡阶段加入1.5倍/2倍逃逸幅值候选；放大候选仍逐步接受扫掠碰撞硬门、真实三步累计反馈和24步绝对上限约束。只有更大候选被硬门接纳并产生更大的真实位移，才进行下一轮GPU。
