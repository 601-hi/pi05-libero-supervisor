# 递增回退深度与密集几何安全点 CPU 节点（2026-10-02）

## 用户从视频指出的问题

v13 三次恢复共只有36个 JOIN 动作且没有 REPLAY。状态机一进入最近历史点的12 mm邻域就立即重规划；变化计划失败后，回退深度又从最近层开始。因此机械臂一直在柜沿正上方的相似观察状态重规划，计划数值虽变化，任务条件并未真正恢复。

## 修复

1. 策略交接必须同时满足最小回退执行步数与最小历史深度；到达最近JOIN点后继续倒序回放，不再立即重规划。
2. 第一次恢复要求20个回退动作和6个历史步；后续失败依次增加15个动作和6个历史步，即20/6、35/12、50/18。
3. changed只清理失败动作块，不再清零本回合恢复深度；重复计划层级与任务效果失败次数取更深者。
4. 超过三级显式安全停止，不允许无限回退—重规划循环。

## 密集安全点

已有MuJoCo碰撞oracle等价于评测阶段拥有已标定机器人—环境几何。历史状态若自碰与环境有符号距离都至少5 mm，且关节/奇异性硬门正常，就标记为`geometry_clear_dense`并逐步保留，不再受3步间隔或动力学似然未知影响。它只认证历史点本身；点间连接仍逐微步经过扫掠碰撞门，绝不从失败点直线跳到远点。

v13 episode2前82步离线审计得到51个密集几何安全点。第一次20/6要求有45个候选，最晚可到action71；第二次35/12因柜沿附近净空不足会自动退至action52或更早；第三次50/18同样有44个候选。这证明递增深度在现有数据中可执行，而不是只有参数没有历史支撑。
