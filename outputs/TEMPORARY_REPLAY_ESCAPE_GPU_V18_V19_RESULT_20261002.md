# REPLAY 临时逃逸 GPU v18/v19 结果（2026-10-02）

## 冻结条件

两轮均使用 LIBERO-90 task0 episode2、seed7、固定扩散噪声2026092700和同一回退门。v18验证独立预算；v19只增加逐步真实净空反馈和方向禁用。

## v18：独立预算正确，但开环方向预测错误

v18最终失败，245个总动作、163个恢复动作，其中JOIN 34、普通REPLAY 126、临时逃逸3。计数恒等式成立：34 + 126 + 3 = 163，证明逃逸没有挤占普通REPLAY预算。一次近点跳过将目标从action65推进到action62，随后触发3步逃逸。

候选器预测前两步`x-`分别增加约0.210/0.211 mm自碰净空，但真实净空由1.783 mm降至1.759 mm，再降至1.689 mm。第三步`z-`后真实净空回升约0.030 mm，仍不足以恢复direct。最大空间撤离7.73 cm、历史深度12，未达到10 cm交接门；按连续3步上限停止，累计12步预算仅使用3步。

## v19：真实反馈阻止重复错误方向

v19把连续限制改为“同一方向最多3步”，并在每步后比较真实自碰净空；无实际改善的轴向方向立即在本次逃逸中禁用，整次恢复总预算仍为12步。实际依次尝试`z-、x-、y-、y+`四个不同方向，每个方向只执行一次，均未达到0.01 mm真实改善要求，随后没有剩余合格方向并安全停止。

v19最终失败，261个总动作、179个恢复动作；JOIN 46、普通REPLAY 129、临时逃逸4。最大空间撤离提高到8.60 cm，历史深度仍为12，仍未进入重规划。最终原因是`swept_collision_gate_rejected_all_candidates`而非预算耗尽。

## 结论

独立预算和反馈式分配均按设计工作，但没有产生端到端收益。当前瓶颈不是逃逸步数太少，而是末端候选经局部关节增量预测得到的自碰净空改善，在该柜沿姿态附近与真实仿真响应不一致。继续把3或12调大只会扩大模型误差风险。

下一步应在无卡阶段对候选预测关节增量、执行后真实关节增量、最小碰撞对切换进行逐步审计，判断误差来自局部逆运动学、控制器动态滞后还是最小碰撞对切换；在原因明确前不再增加GPU实验或放宽碰撞门。
