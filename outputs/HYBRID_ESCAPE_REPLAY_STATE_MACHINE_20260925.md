# 安全脱困—倒序回放状态机

日期：2026-09-25

## 目标

将此前分散的候选评分、汇合许可与倒序状态参考整合成不直接执行动作的控制平面。状态机只输出下一步请求，由硬安全门、候选评分器、机器人控制器和响应监督器分别提供证据与执行。

## 状态

`idle -> hold_and_settle -> safe_escape -> reverse_replay -> reobserve_and_replan`

任意阶段的硬故障进入`safe_stop`。回放普通异常返回`hold_and_settle`，重新稳定并再次安全脱困；重试预算耗尽后进入`safe_stop`。

## 关键约束

- 稳定状态必须连续确认，单帧低漂移不能触发脱困；
- 汇合许可同时要求关节误差、末端误差、关节速度、碰撞安全分和硬门连续满足阈值；
- 候选全部拒绝时先缩小步长重评，达到预算后停止，禁止选择“最不坏”的危险动作；
- 高频倒序参考只有在当前参考确实到达后才能推进；
- 单个参考超时或响应监督异常立即退出回放并重新汇合，禁止跳过历史状态；
- 回放完成只进入重新观察和π0.5重规划，不直接宣称任务恢复。

## CPU验证

冻结合成协议覆盖四条路径：

- 正常路径最终进入`reobserve_and_replan`；
- 全部候选连续拒绝最终`safe_stop`；
- 回放重复中断耗尽重试预算后`safe_stop`；
- 任意硬故障立即`safe_stop`。

四项安全断言均为true。定向测试27项、完整回归345项全部通过。审计产物为`outputs/HYBRID_RECOVERY_PROTOCOL_AUDIT_20260925.json`。
