# 可信检查点回退 GPU/MuJoCo smoke（2026-09-25）

## 目的与边界

验证公开Panda运动学测量和“历史状态作路标、确定性控制器重新闭环返回”的动力学可达性。该实验是 plumbing-only，不是任务恢复评测，也不是严格安全认证。

## 纯记录策略 smoke

LIBERO spatial task 0，seed 7、固定扩散噪声2026092501：

- 任务成功；
- 78个动作、16次策略推理；
- 监督器无控制权；
- 0次报警、0次重规划；
- 78/78步 `kinematic_measurement_status=ok`；
- 关节限位最小余量约0.621–1.316 rad；
- 末端平移Jacobian最小奇异值约0.220–0.276。

无接触、恢复观察质量和任务阶段继续为null，因此严格可认证检查点仍为0。

## 回退协议

1. 重放同一成功轨迹前30步；
2. 目标为历史action 20；
3. 路标为29→26→23→20；
4. 每步最大末端平移5 mm；
5. hold直到连续3步漂移低于0.3 mm；
6. 硬故障/高置信接触立即停止，普通方向跟踪使用3步累计响应；
7. 当前路标未到达不得切换到更早路标；
8. 历史关节走廊、关节余量和奇异性每步检查。

## 失败与修正

### 第一次

无稳定阶段，首个反向动作被原运动残余主导，单步方向门要求重新规划。说明“指令改变后实际速度立即反向”是假设过强。

### 第二次

固定hold 5步后漂移仍约0.94 mm/步。改为动态稳定条件，并把普通跟踪检查改为3步累计；硬故障仍立即响应。

### 第三次

窗口判断允许连续36步正常回退，但每路标12步不足，脚本错误地继续切换更早路标，最终被历史走廊偏离门拒绝。修正为路标超时必须停止，并将smoke单路标预算增至50步。

## 最终结果

- 动态稳定阶段：15步，最终漂移约0.130 mm/步；
- 访问路标：29、26、23、20；
- 回退动作：109步；
- 107次累计响应为safe，前2次为warming-up；
- 执行前拒绝：0；
- 最大单步参考平移：5 mm；
- 最终末端位置误差：1.753 mm；
- 独立重复两次，命令序列与每步末端状态逐值相同。

## 仍未解决

- `occupancy_clear=True` 是明确记录的测试假设；
- 没有力/力矩或独立接触传感器；
- 未证明掉落物或新障碍出现后历史走廊仍安全；
- 没有接入在线异常诊断、任务阶段回退、π0.5候选重采样或最终任务成功率评测；
- 因而 `strict_safety_certified=false`。

下一阶段必须先补可部署的走廊占用/接触证据，再把回退接入shadow在线链；不能直接把本smoke升级为自动控制。
