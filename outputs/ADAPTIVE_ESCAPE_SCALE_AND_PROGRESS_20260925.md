# 自适应脱困尺度与连续进展监测

日期：2026-09-25

## 动机

真实微步实验中，prefix60和70的全部2–5 mm候选被总碰撞风险门拒绝。此前状态机虽输出`reduce_step_and_rescore`，候选生成尺度并未实际改变。本节点把该口令实现为有限、可审计的尺度调度。

## 自适应尺度

默认三级候选尺度：

1. 2 / 3.5 / 5 mm；
2. 1 / 2 / 3 mm；
3. 0.5 / 1 / 2 mm。

候选全部拒绝或执行响应不安全时降一级；最小尺度仍失败则返回`exhausted`，不能继续缩到控制噪声以下。只有连续多步响应安全且碰撞风险确实改善，才允许放大一级，避免单次偶然成功造成激进动作。

## 连续进展

新增窗口监测只承认两种进展：碰撞风险下降，或历史汇合误差下降。单纯存在末端位移不算恢复进展。窗口内两者均无改善则`stalled`；碰撞风险恶化超过上限则`replan`；历史不足为`warming_up`。

这解决了此前项目中“失败轨迹仍持续运动，因此运动本身不能证明恢复”的核心问题。

## 验证

- 全候选拒绝会依次生成两级更小尺度；
- 最小尺度耗尽显式停止；
- 连续安全改善后才重新放大；
- 不安全响应会继续缩步并在最小尺度停止；
- 无安全/汇合改善的持续运动判为stalled；
- 风险明显恶化判为replan。
