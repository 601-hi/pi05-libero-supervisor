# 条件执行双专家在线适配与自然轨迹回放（2026-09-13）

## 完成内容

将五成员条件关系双专家封装为有状态在线 scorer，并接入 `CallbackExecutionMonitor` 工厂。部署特征只含公开可测的动作、EEF、关节和夹爪状态；明确禁止 task id、reward、success、disturbance label 与对象状态进入特征。

冻结专家的真实目标不是单个 progress，而是当前实际 EEF 位移相对于当前及前五个指令的六个 directed-progress。条件向量还包含归一化关节位置、关节限位余量、EEF 相对 episode 起点的位置、夹爪开度、指令方向/幅值、旋转幅值、前一步 EEF 响应和前一步 progress。在线状态在每个 episode 及重规划边界显式重置。

冻结判分为：五成员异常/正常对数似然比的均值减去一倍成员标准差，再取十步因果均值。阈值 `2.6228122472763062` 完全来自 DROID 源域保留正常序列，未使用 LIBERO 标签重新标定。由于 scorer 内部已经完成十步融合，工厂中的 execution mismatch 使用 1-of-1；其他故障仍可使用各自 k-of-m。

## 数值验收

新在线适配器与原批量离线评分器在一条 103-step LIBERO 轨迹上逐步比较：正常 logp、异常 logp、似然比和 ensemble std 的最大绝对误差均小于 `0.001`，验收 PASS。误差来自 float32 逐步/批处理舍入顺序。框架相关测试 9/9 通过。

## 自然轨迹开放诊断

在 55 条既有自然轨迹上保持源域阈值不变：31 成功、24 失败。结果如下：

| 时间规则 | 检出的失败 episode | 误报的成功 episode |
|---|---:|---:|
| 1-of-1（十步分数越阈） | 20/24 | 12/31 |
| 2-of-3 | 19/24 | 10/31 |
| 3-of-5 | 17/24 | 9/31 |
| 4-of-7 | 14/24 | 7/31 |

投票能降低部分尾部误报，但无法消除跨域漂移，并以召回下降为代价。这里的“失败”是任务结果，不是经过人工机制标注的执行失配；策略指令错误或对象放置失败本来就不一定该由执行一致性专家报警。因此该表只能作为开放诊断，不能宣称执行失配召回率。

## 当前结论

软件接入与数值复现已经完成，但该专家只能标记为 `source_calibrated_candidate`，不能标记为 target-validated。下一步需要建立失败时间区间与机制标签，将执行受阻/响应衰减和策略停滞、对象结果错误分开评价；同时探索只依赖目标域正常启动数据的在线尾部适配，不能用测试异常标签调整阈值。
