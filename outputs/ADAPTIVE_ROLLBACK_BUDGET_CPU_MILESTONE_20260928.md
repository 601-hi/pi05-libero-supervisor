# 自适应回退预算 CPU 节点（2026-09-28）

> 阶段边界补充：v6 episode2 的回放被 JOIN 禁忌器污染38次，所以“发散→拒绝续期”只验证预算判据，不能代表纯回放器本身发散。现已隔离：禁忌/mask/脉冲仅用于 JOIN；REPLAY 仅走 direct 历史候选并保留碰撞硬门。

## 动机

人工视频显示，固定的汇合/回放预算与“小步安全逃逸—闭环汇合—倒序回放”的恢复方式不完全匹配。v6 日志进一步表明，预算耗尽既可能发生在仍然收敛时，也可能发生在平台化或发散时，因此不能统一增加预算。

## 机制

- 汇合软预算 320、回放软预算 160；它们是复核点，不再必然终止。
- 最近20步对同一局部目标的误差净下降至少0.5 mm，且线性斜率小于等于 -0.01 mm/步时，续80步。
- 汇合硬上限640、回放硬上限480，永不无限续期。
- 回放目标索引变化时清空误差窗口，禁止比较不同目标的误差。
- 碰撞/运动学硬门优先；无安全候选时预算器无权续跑。
- 默认关闭，便于严格配对和回滚。

## v6 反事实结果

- episode0 回放末端仍在收敛：应从160续至240。
- episode2 回放末端发散：拒绝续期。
- episode4 汇合末端发散：拒绝续期。
- episode1 在软预算前被碰撞门终止：预算器不介入。
