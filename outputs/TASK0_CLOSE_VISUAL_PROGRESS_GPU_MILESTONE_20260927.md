# Task 0 抽屉关闭视觉进展 GPU 节点（2026-09-27）

## 目的

已知 LIBERO-90 task 0 的唯一目标是 `Close(top_drawer)`。此前严格配对实验中，策略能够一致地搬运干扰物黑碗，却始终没有完成关闭抽屉。本阶段建立第一条真实关系感知链，检验视觉能否发现“执行仍在继续，但任务目标没有推进”。

## 数据防火墙

- 开发：seed37 episode3 成功轨迹、seed34 episode0 自然失败轨迹；
- 留出：seed35 episode3 成功，以及 episode0/1/2/4 四条失败；
- 在线特征只使用固定相机 RGB、腕部 RGB、任务关系查询和首帧候选；
- reward、episode outcome、仿真对象位姿与成功谓词均禁止进入视觉特征；
- seed35 只在规则冻结后打开结果，不据其重新调阈值。

## 三个被否决的捷径

1. **直接查询 `top drawer`**：Florence-2 和 Grounding DINO 都优先选中左侧错误柜体。改成状态感知查询 `open top drawer` 后，真实开放抽屉成为首选候选。
2. **固定首帧框 IoU**：开发成功可检出，但留出失败 2/4 被误判为关闭。原因是开放抽屉本身会移动，固定框把机构运动误当成状态完成。
3. **open/closed 语言分数对比**：`closed top drawer` 在仍开放的失败轨迹上反而常得更高分；开放词汇检测分数不是机构状态概率。

这些负结果再次确认：语义模型适合提出候选，不适合单独证明连续物理状态。

## DINO + SAM2 进展量

首帧由 DINO 的 `open top drawer` 查询初始化开放区域，SAM2 随后跟踪该区域。定义：

\[
p_t=1-\frac{A_t}{A_0},
\]

其中 \(A_t\) 是开放区域跟踪掩膜面积。该量不能可靠判断最后几毫米是否完全闭合，但能表示显著推进、平台化和回退。

冻结的保守看门狗只产生两类异常：

- 长期没有显著进展，输出 `goal_no_progress`；
- 达到过较好进展后明显退化，输出 `goal_regression`。

它明确不输出 `satisfied/complete`。完全闭合仍保持 `uncertain`，需要更可靠的机构端点证据或任务执行终止信号。

就当前小样本而言，成功保持率 2/2，失败检出 4/4；四条失败原本均运行到 400 步，因此检测提前约 303–320 步。由于开发成功和留出成功各只有一条，且仅覆盖同一任务与场景，这不是可宣称的泛化准确率。

## 机器人学解释

抽屉是一个受约束的移动副。首帧框并不是机构状态坐标：抽屉沿关节方向运动时，投影框理应平移、缩放甚至发生遮挡。正确的监督量应近似关节进度，而不是与初始像素框的一致性。SAM2面积仍只是单目代理量，无法取代抽屉关节编码器或精确三维重建；其合理角色是检测明显的单调进展、停滞和退化。

## 当前准入边界与下一步

- 可以进入 shadow：`goal_no_progress` / `goal_regression`；
- 不得据此宣布任务完成，也不得独立授权危险动作；
- 下一 CPU 阶段把进展看门狗输出接入统一 `RelationEvidence` 与重规划路由；
- 下一 GPU 验证应扩展到其他 `Open/Close` 场景和不同相机边界，而不是继续在 task 0 调阈值；
- 端到端比较必须使用同服务、同 seed、同采样噪声的 baseline/control，并统计 rescued、harmed、preserved success 与 unresolved failure。
