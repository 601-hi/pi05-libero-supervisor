# 纯关节空间完整回退 CPU 节点（2026-10-02）

## 目标

落实“恢复阶段精确控制每个关节电机并从关节层面倒序回放历史构型”。本版本不再把历史关节姿态仅作为 OSC 零空间弱目标，也不直接写 MuJoCo `qpos`。

## 控制结构

正常执行仍为 π0.5 的 `OSC_POSE`：六维末端增量加夹爪。进入 JOIN/REPLAY 后，每个恢复周期临时切换到 robosuite `JOINT_POSITION`，动作变成七个独立关节位置增量加夹爪：

\[
e_{i,t}=q^{hist}_{i,k}-q_{i,t}
\]

\[
\Delta q^{raw}_{i,t}=\operatorname{clip}
(e_{i,t},-0.02,0.02)
\]

\[
\Delta q_{i,t}=\Delta q_{i,t-1}+
\operatorname{clip}(\Delta q^{raw}_{i,t}-\Delta q_{i,t-1},-0.006,0.006)
\]

随后按控制器每步 `0.05 rad` 的公开缩放转换为归一化关节动作。七个关节分别闭环，不由逆运动学重新选择构型。历史点到达条件也改成每个关节都满足：

\[
\max_i |q_{i,t}-q^{hist}_{i,k}|\le 0.025\;\mathrm{rad}
\]

每步预计关节目标继续经过原扫掠自碰撞/环境碰撞硬门。控制器输出力矩并由 MuJoCo 解算动力学；没有状态瞬移。一步结束后无论成功或异常，都在 `finally` 中恢复原 OSC 控制器与原七维策略动作接口。

## 与 v23 的本质区别

- v23：末端六维任务优先，历史关节只作用于一个冗余零空间方向；不能保证七关节回到历史值。
- 本版本：恢复期间停止 OSC，由 JOINT_POSITION 直接向七个电机对应的关节伺服目标发命令；历史七关节值就是主控制目标。

当前先验证纯关节回退。后续可配置为分级模式：正常使用末端回退，只有末端误差长期不降或笛卡尔候选全拒绝时才切换到关节回退；本轮不混合两者，以保持因果清晰。

脚本：`outputs/run_direct_joint_replay_gpu_v24_20261002.sh`。冻结与 v22/v23 相同的 LIBERO-90 task0 episode2、环境种子、π0.5扩散噪声、监督器和重规划参数；唯一核心变化是启用纯关节回退并关闭 v23 零空间模式。下一轮重点比较：七关节最大/均方误差、历史索引推进速度、实际空间撤离、碰撞拒绝位置、是否达到10 cm交接门及最终任务成功。

## GPU v24f--v24h 结果与可复现性审计

- v24f 完成 `34 JOIN + 126 REPLAY` 个直接关节控制步，最大空间撤离约 `9.44 cm`，历史深度达到 13；这相较早期只走 2--30 步的版本，证明控制器切换制动和七关节伺服能稳定推进历史回放。
- v24f 未达到重规划门：还差约 `5.6 mm` 空间撤离和 5 个历史层级，最终被 `link5_collision--gripper_hand_collision` 的固定正净空下限拒绝。末步实际自间隙约 `2.004 mm`、下一步预测 `1.693 mm`，环境间隙约 `28.6 mm`。
- 正常触发前历史审计显示，同一相邻机构碰撞几何在动作 59--61 本来就会达到约 `-0.18 mm` 至 `+0.07 mm`，而没有真实自碰撞故障。因此固定要求历史回放保持 1.5--1.75 mm 正间隙，会禁止机器人返回它已安全经历的姿态。仅对严格直接历史关节回放加入 `-0.5 mm` 简化碰撞网格容差；JOIN、自由逃逸和环境碰撞规则不变。相关回归现为 `147 passed`。
- 但 v24g/v24h 暴露更靠前的实验问题：即使环境种子与扩散噪声相同，三轮从动作 0 起的策略动作已经不同，动作最大差约 `0.04--0.19`，第 1 步起关节和末端状态也开始分叉。固定扩散噪声只能保证相同观测下的采样一致，不能冻结环境图像和完整推理输入序列。因此 v24g 在 `37 JOIN + 119 REPLAY` 停止，v24h 更在 `27 JOIN` 停止，不能作为单变量阈值消融。

结论：纯关节空间执行通道已经通过 CPU 闭环和 GPU 长回放验证，但尚未证明端到端重规划成功。下一次昂贵 GPU 比较前必须保存同一个故障触发时刻的 MuJoCo state、控制状态和历史缓冲，并从该快照重复启动恢复；否则每次从 episode 起点重跑会把上游轨迹漂移混入回退器比较。
