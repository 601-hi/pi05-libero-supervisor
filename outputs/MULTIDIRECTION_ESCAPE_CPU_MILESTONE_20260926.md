# 多方向、多尺度安全逃逸 CPU 里程碑（2026-09-26）

## 动机

上一轮严格配对证明：直接朝历史汇合点的第一步可能把预测环境间隙从0.768 mm降到0.200 mm，而真实执行会进入约3 mm接触。加入模型误差缓冲后能够提前拒绝该动作并安全退化到π0.5重规划，但还不会主动寻找另一条增加间隙的逃逸方向。

## 候选库

每个在线回退周期从原6D汇合控制器得到一个参考动作，再构造最多21个候选：

- 3个`direct`候选：参考平移与旋转同时缩放为0.25、0.5和1.0；
- 18个`escape_axis`候选：在末端动作坐标的±X、±Y、±Z上分别使用0.25、0.5和1.0尺度；
- 轴向逃逸候选暂时把旋转置零，避免平移、姿态耦合使碰撞原因不可辨；
- 所有候选保持当前夹爪命令不变。

参考控制器单步平移上限为3 mm，因此轴向候选对应的最大等效步长约为0.75、1.5和3 mm。它们不是直接写关节状态，仍由当前Jacobian预测关节响应，并逐个经过MuJoCo扫掠碰撞门；未来真机应替换为机器人碰撞模型/占用场和实时传感证据。

## 选择规则

排序不会把历史误差置于碰撞安全之前：

1. 缺失距离、非有限距离、继续恶化缓冲区内间隙的候选直接淘汰；
2. 若存在安全的`direct`候选，选择最大安全尺度，继续原倒序回放目标；
3. 只有全部直达候选失败时才启用`escape_axis`；
4. 轴向逃逸首先选择最小安全尺度，再最大化“自碰撞与环境间隙增益中的较差者”，最后才比较与历史汇合方向的一致性。

这相当于碰撞风险是硬约束和第一目标，历史汇合只是安全集合内的次级目标，符合此前提出的动态权重思想的保守首版。

## 可审计性与验证

每个候选都写入`complex_rollback_candidate`事件，包含候选ID、类型、尺度、起止自碰撞/环境间隙、最差间隙增益、汇合方向一致性、是否通过及是否被选中；另保留汇总`complex_rollback_proposal`事件以兼容既有分析工具。

新增测试覆盖：候选数量与唯一ID、夹爪保持、逃逸候选旋转隔离、缓冲区规则、穿入状态分步逃逸、最大安全直达优先、直达失败后最小尺度逃逸及间隙增益排序。完整项目回归443项通过，Python语法检查通过。

## 边界与下一GPU步骤

当前结果证明控制逻辑和数据契约一致，尚未证明MuJoCo中一定存在可行逃逸方向，也未证明局部Jacobian的预测误差已被完全覆盖。下一次GPU只重跑冻结的task4动作40--52机制探针：检查是否从21个候选中选择增加间隙的微步、实际间隙是否与预测同向改善、是否最终汇合/回放或安全退化。该探针不进入最终无偏成功率统计。
