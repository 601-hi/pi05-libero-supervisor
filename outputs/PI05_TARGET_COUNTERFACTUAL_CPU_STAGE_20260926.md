# π0.5目标候选反事实pilot准备（CPU，2026-09-26）

## 决策

当前可导出的4×4×2048视觉latent来自每路图像的SigLIP patch token池化，尚未经过任务语言条件化。π0.5现有推理接口只输出动作，不输出目标框、对象类别logit或目标词注意力。因此不能直接把视觉latent与任务名词计算相似度并称为目标概率。

为降低独立视觉语义模型的成本，第一版改为行为反事实候选排名：SAM2提供有限候选掩膜；固定同一π0.5扩散噪声，分别在原图、候选模糊和候选中性填充图上推理；用前5步动作计划变化衡量该候选对当前语言条件策略的因果影响。只有两种扰动的Top-1相同且最低排名间隔达标才输出候选，否则弃权。该分数仍是动作敏感性，不是语义概率，目标、障碍物和目标容器都可能高分。

## 重要时序限制

task31闭爪帧中目标已被夹爪明显遮挡。即使反事实排名有效，正式方案也应在更早、目标清晰的重规划帧初始化，再用SAM2跟踪；闭爪帧只适合做极小可行性试验，不能据此声称一般目标识别已解决。
